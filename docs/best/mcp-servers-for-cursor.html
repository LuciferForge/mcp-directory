1. PostgreSQL MCP Server: Direct DB Schema Inspection

Instead of manually dumping SQL dumps or copying schemas into chat, the Postgres MCP server allows Cursor to run SELECT queries, inspect table structures, and write bug-free migrations with zero guesswork.

{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-postgres",
        "postgresql://username:password@localhost:5432/my_database"
      ]
    }
  }
}

2. GitHub MCP Server: Pull Requests & Issue Automation

With the official GitHub MCP server, Cursor can read issues, inspect git blame history, review diffs across branches, and automatically file PR reviews directly from your editor prompt.

3. How to Configure Cursor (.cursor/rules/mcp.mdc)

To ensure Cursor's agent uses your MCP tools reliably, add a dedicated rule file inside your repository at .cursor/rules/mcp.mdc:

---
description: MCP Tool Usage Protocols for Cursor
globs: **/*
alwaysApply: true
---

# MCP Protocol Standards
1. Prefer official Model Context Protocol tools for database schema introspection.
2. When querying databases, always execute read-only queries with strict LIMIT clauses.
3. Validate tool arguments with schema definitions before invoking.
4. Send runtime debug logs to stderr to prevent breaking JSON-RPC communications.
